
# Alt Mobility Data Analysis Intern Assignment

## Approach
- **SQL Analysis**: Queries for order, customer, payment, and detailed order reports.
- **Cohort Analysis**: Python script to visualize customer retention.
- **Data Cleaning**: Handled date parsing and missing values.

## Files
- `queries.sql`: All SQL tasks (1-4).
- `retention_analysis.py`: Cohort analysis script.
- `retention_heatmap.png`: Retention visualization.

## How to Run
1. Import `customer_orders.csv` and `payments.csv` into my SQL database.
2. Execute SQL queries in `queries.sql`.
3. Run `retention_analysis.py` (requires pandas, matplotlib, seaborn).
